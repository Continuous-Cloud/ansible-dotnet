## Usage

Supported versions can be found below (or in the vars file)<br>
In your playbook you can include the role as you normally would.
```
---
- name: example
  hosts: localhost

  roles:
  - netcore
```
To specify version 2.1 SDK:
```
---
- name: example
  hosts: localhost
  vars:
    netcore_type: sdk
    netcore_version: 2.1
  roles:
  - netcore
```
To specify more than one version:
```
---
- name: example
  hosts: localhost
  vars:
    netcore_type: sdk
  roles:
  - name: netcore
    vars:
      netcore_version: 2.1
  - name: netcore
    vars:
      netcore_version: 2.2
```
